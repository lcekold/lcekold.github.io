团设题目：基于STM32的智慧校园控制与能耗分析系统

团设大致功能：

1. 校园设备本地控制(STM32)实现教室/实验室的照明与风扇等基础设备的本地控制支持光照感应与温湿度检测，实现自动化环境调节(如自动开关灯、风扇)。

2. 远程控制与数据采集(树莓派)接收上位机/服务器控制指令并转发至STM32;定时采集各区域用电、环境参数、设备状态等信息，上传服务器。

3. 智慧校园控制客户端(Qt)实现教室、办公室、实验室等区域的远程控制(照明、空调、门禁等):显示各区域设备状态与传感器数据的实时反馈:提供图表化能耗数据分析，支持对比不同时间段/区域能耗变化。

4. 服务器模块功能:多用户账号系统，支持学校不同角色(如管理员、教师、后勤)登录与权限控制;每日、每月能耗数据统计与报表生成;支持设置自动化控制规则(如上下课时间自动控制设备开关、节假日模式等);支持异常用电报警(如超额耗电提醒)

电流传感器（例如ACS712）：用于检测电路中的电流。
电压传感器（例如ZMPT101B）：用于检测电路中的电压。
电能计量芯片（例如ADE7753）：用于计算电路中的功率和能耗。

# 智慧校园控制与能耗分析系统设计方案

## 1. 项目概述
本项目旨在构建一个集环境感知、自动化控制、远程管理与能耗大数据分析于一体的智慧校园系统。系统采用分层架构设计：底层采用 **STM32** 进行终端控制，中间层利用 **树莓派** 作为边缘网关进行数据汇聚，上层通过 **服务器** 与 **Qt客户端** 实现数据可视化与交互管理。

---

## 2. 硬件选型与分析

本系统硬件设计遵循“模块化、低功耗、高稳定性”的原则。

### 2.1 核心控制与网关层

| 硬件名称 | 选型型号 | 选型原因 | 主要作用 |
| :--- | :--- | :--- | :--- |
| **终端控制器** | **STM32F103C8T6** (Blue Pill) | 1. 性价比高，资源丰富(Flash/RAM足够)；<br>2. 拥有丰富的外设接口(ADC, USART, I2C)；<br>3. 库函数成熟，便于团队开发。 | **现场控制核心**：负责读取传感器数据，执行PID或阈值逻辑，控制继电器与风扇，并通过串口/无线模块通信。 |
| **边缘网关** | **Raspberry Pi 4B** (或5B) | 1. 运行Linux系统，支持多线程与Python/C++开发；<br>2. 强大的网络协议栈，易于对接云服务器；<br>3. 算力足以处理本地数据的清洗与暂存。 | **数据中转枢纽**：通过UART/ZigBee接收STM32数据，打包为JSON格式上传服务器；接收服务器指令下发给STM32。 |

### 2.2 传感器与执行器层

| 硬件名称 | 选型型号 | 选型原因 | 主要作用 |
| :--- | :--- | :--- | :--- |
| **温湿度传感器** | **DHT11** 或 DHT22 | 数字信号输出，单总线通信，占用IO少，且DHT11成本低廉，适合大范围部署。 | 采集教室/实验室环境温湿度，用于联动风扇或空调控制。 |
| **光照传感器** | **BH1750** | I2C接口数字传感器，比光敏电阻精度高，抗干扰能力强，直接输出Lux值。 | 检测室内光照强度，实现“光暗自动补光”或“人走灯灭”逻辑辅助。 |
| **电能计量模块** | **PZEM-004T** | 工业级交流电参数测量模块，串口通信，可测电压、电流、功率、电能。 | **核心组件**：精确采集设备用电量，是“能耗分析”功能的数据来源。 |
| **继电器模块** | **5V 光耦隔离继电器** | 强弱电隔离，安全性高，驱动能力强(10A/250VAC)。 | 控制教室照明灯具（模拟220V设备）的通断。 |
| **电机驱动** | **L9110S** 或 MOS管 | 能够进行PWM调速，体积小。 | 驱动直流风扇，实现根据温度自动调节转速。 |     

### 2.3 通信模块

| 硬件名称 | 选型型号 | 选型原因 | 主要作用 |
| :--- | :--- | :--- | :--- |
| **无线通信** | **ESP8266 (Wi-Fi)** 或 LoRa (SX1278) | 若节点密集选Wi-Fi方便组网； | 实现STM32终端与树莓派网关（或路由器）之间的无线数据传输。 |

## 3. 系统功能详细设计

系统软件分为四大功能模块：终端感知层、边缘网关层、服务器业务层、客户端交互层。

### 3.1 终端感知与控制子系统 (STM32)
该模块运行在STM32上，负责最底层的硬件交互。

* **多源数据采集功能**
    * **环境监测**：实时轮询读取DHT11温湿度数据和BH1750光照强度数据。
    * **能耗计量**：通过串口定时读取PZEM-004T的电压、电流、累计电能数据。
* **本地自动化逻辑控制**
    * **光照闭环**：当光照低于阈值且红外检测到有人（可选）时，自动闭合继电器开启照明。
    * **温控风扇**：根据温度梯度输出不同占空比的PWM波，实现风扇无级调速。
    * **指令解析**：解析来自上位机的控制帧（如 `CMD:FAN_ON`），执行强制开关操作。

### 3.2 边缘网关与数据传输子系统 (Raspberry Pi)
该模块运行在树莓派的Linux环境上，主要使用Python或C++编写。

* **协议转换与转发**
    * **下行通信**：通过串口或Socket接收STM32上传的原始数据包。
    * **上行通信**：将原始数据封装为标准JSON格式，通过MQTT或HTTP POST协议发送至云服务器。
* **本地指令路由**
    * 监听服务器下发的控制指令，根据设备ID将指令精准路由发送给指定的STM32节点。
* **断网续传**
    * 在网络异常时，将采集的数据暂存至本地SQLite数据库，待网络恢复后自动补传，保证能耗数据连续性。

### 3.3 服务器业务逻辑子系统 (后端)
该模块部署在云服务器或局域网服务器上，负责核心逻辑处理。

* **用户权限管理体系 (RBAC)**
    * **超级管理员**：拥有系统所有权限，包括添加设备、删除用户。
    * **后勤人员**：仅查看能耗报表，接收异常报警，控制公用设备。
    * **普通教师**：仅拥有自己所在教室/实验室的设备控制权。
* **自动化规则引擎**
    * **定时任务**：支持设置类似Crontab的任务（如：每晚23:00强制关闭所有教学楼灯光）。
    * **场景模式**：一键切换“上课模式”（灯光全开）、“投影模式”（前排灯关）、“节假日模式”（所有设备断电）。
* **异常监控与报警**
    * **超额预警**：当某区域实时功率超过设定阈值，或每日耗电量突增，服务器通过邮件或客户端推送报警信息。

### 3.4 智慧校园客户端子系统 (Qt C++)
该模块是用户交互的窗口，运行在PC端（管理员/监控室）。

* **可视化数据大屏**
    * **实时状态**：以图形化UI（如灯泡图标点亮/熄灭）展示各教室设备开关状态。
    * **环境仪表盘**：使用仪表盘控件动态显示当前的温度、湿度和光照值。
* **能耗数据分析 (Charts)**
    * **趋势分析**：利用 QChart 绘制折线图，展示某教室24小时功率变化曲线。
    * **对比分析**：利用柱状图对比不同实验室的月度用电量，找出“高能耗”区域。
* **远程交互控制中心**
    * 提供虚拟开关按钮，用户点击后，指令经由 `Qt -> Server -> Raspberry Pi -> STM32` 的链路并在毫秒级内响应。

# 1.C语言的编译过程原理

**答**：C语言的编译过程通常分为四个主要阶段：预处理、编译、汇编和链接。每个阶段完成特定的任务，最终将源代码转换为可执行程序。

首先通过预处理器处理宏定义、头文件包含等；然后由编译器将预处理后的代码翻译成汇编语言；接着汇编器将其转换为机器相关的目标文件（二进制）；最后链接器将多个目标文件和库函数合并生成一个完整的可执行文件。

# 2.void*类型指针作用是什么，对比char*、int*等有什么优势

**答**：void* 类型指针是一种“无类型指针”或“通用指针”，它不指向任何特定数据类型，可以用来存储任意类型对象的地址。与 char*、int* 等具体类型的指针相比，void* 的主要作用是提供类型无关的指针抽象，常用于泛型编程、内存管理函数（如 malloc）、函数参数传递等场景。其优势在于灵活性和通用性，但不能直接解引用或进行指针算术运算。

# 3.大端模式和小端模式，内存对齐（char、int、char的结构体32位系统中占用多少个字节）

**答**：在32位系统中，一个包含char、int、char的结构体（按声明顺序）通常占用12个字节。这是由于内存对齐规则和小端或大端模式共同作用的结果，其中大端和小端影响的是多字节数据在内存中的存储顺序，而结构体大小主要由内存对齐决定。

# 4.SPI的四种模式，SPI如何和从机通信（通信协议帧）、如何实现一主多从（多条SS片选线）

**答**：SPI（Serial Peripheral Interface）有四种工作模式，由时钟极性（CPOL）和时钟相位（CPHA）两个参数决定。SPI通过主从架构进行全双工同步通信，通信帧通常由片选信号（SS）、时钟信号（SCLK）、MOSI（主出从入）和MISO（主入从出）组成。

实现一主多从的方式有多种：

独立片选线法：为主从设备各自分配独立的片选线（SS），每次通信前主设备拉低目标从设备的片选线以选中该设备。

菊花链（Daisy Chain）方式： 所有从设备串联，MISO连到下一个的MOSI，共用一条SS和SCLK。 数据从第一个传到最后一个，适合移位寄存器类器件（如74HC595）。 缺点：延迟大，不适用于高速或独立寻址场景。

码器辅助选择（扩展）： 使用3-8译码器将3根地址线转为8根片选线，节省主控GPIO资源。

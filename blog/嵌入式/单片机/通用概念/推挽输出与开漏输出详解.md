# 推挽输出与开漏输出详解

## 一、先说核心结论

| 输出模式 | 能输出高电平？ | 能输出低电平？ | 需要外部上拉电阻？ |
|---------|:------------:|:------------:|:---------------:|
| **推挽输出** | 是（主动推高） | 是（主动拉低） | 不需要 |
| **开漏输出** | 否（只能释放） | 是（主动拉低） | 需要（否则无法输出高电平） |

---

## 二、推挽输出（Push-Pull Output）

### 2.1 名字的字面意思

- **推（Push）**：输出高电平时，内部 PMOS 管导通，把输出引脚"推"到 VCC（电源电压）。
- **挽（Pull）**：输出低电平时，内部 NMOS 管导通，把输出引脚"挽"到 GND（地）。

> "推挽"这两个字形象地描述了上下两个管子交替工作的动作：一个向上"推"，一个向下"挽"。

### 2.2 内部结构示意

```
        VCC
         │
      ┌──┴──┐
      │ PMOS │  ← 高电平时导通，"推"出高电平
      └──┬──┘
         │
    ——→──●────  GPIO 引脚
         │
      ┌──┬──┐
      │ NMOS │  ← 低电平时导通，"挽"下低电平
      └──┴──┘
         │
        GND
```

### 2.3 工作过程

- **写 1 → 引脚输出高电平**：PMOS 导通，NMOS 关断，引脚直接连接到 VCC。
- **写 0 → 引脚输出低电平**：PMOS 关断，NMOS 导通，引脚直接连接到 GND。

两个管子**互补导通**，不会同时导通（否则 VCC 直通 GND 会烧毁芯片）。

### 2.4 特点

| 优点 | 缺点 |
|------|------|
| 驱动能力强，可提供较大电流 | 无法实现"线与"逻辑 |
| 输出电平由电源电压决定，信号完整 | 多个推挽输出不能直接相连 |
| 不需要外部上拉电阻 | — |

### 2.5 典型应用

- 驱动 **LED**（串联限流电阻）
- 驱动 **蜂鸣器**
- **普通 GPIO 控制信号**（如片选、使能脚）
- **SPI、I2S 等单主机通信**的时钟/数据线

---

## 三、开漏输出（Open-Drain Output）

### 3.1 名字的字面意思

- **开（Open）**：上方的管子被"断开"了、不存在了。
- **漏（Drain）**：只剩下下方的 NMOS 管，它的漏极（Drain）直接引出到引脚。

> 所以"开漏" = "漏极开路"，即只有下拉 NMOS，没有上拉 PMOS。

### 3.2 内部结构示意

```
        VCC
         │
        [R]    ← 外部上拉电阻（必需）
         │
    ——→──●────  GPIO 引脚
         │
      ┌──┬──┐
      │ NMOS │  ← 低电平时导通，拉低电平
      └──┴──┘
         │
        GND
```

### 3.3 工作过程

- **写 1 → 引脚输出高电平**：NMOS 关断，引脚处于**高阻态**（浮空）。如果没有外部上拉电阻，引脚电平不确定；加上拉电阻后，引脚被电阻拉到 VCC。
- **写 0 → 引脚输出低电平**：NMOS 导通，引脚直接连接到 GND。

可以看到，开漏输出**不能主动输出高电平**，它只能做两件事：拉低、或者释放（高阻）。

### 3.4 特点

| 优点 | 缺点 |
|------|------|
| 支持**线与**（多个开漏输出可直接并联） | 需要外部上拉电阻，增加 BOM 成本 |
| 可实现**电平转换**（上拉到不同电压） | 上升沿靠电阻充电，速度慢于推挽 |
| 输出高电平时功耗低（只有电阻漏电流） | 驱动能力弱于推挽 |

### 3.5 典型应用

- **I²C 总线**的 SDA 和 SCL 线（必须开漏，实现多主机仲裁）
- **多个输出共用一个中断引脚**（线与，任意一个拉低即触发）
- **不同电压域之间的电平转换**（例如 3.3V 的 MCU 控制 5V 的设备，开漏输出上拉到 5V）
- **漏极开路型 LED 驱动**（如一些 LED 驱动芯片的内部输出级）

## 四、直观对比：推挽 vs 开漏

### 4.1 行为对比

| 操作 | 推挽输出 | 开漏输出（无上拉） | 开漏输出（有上拉） |
|------|---------|:---------------:|:----------------:|
| 输出 1 | 引脚 = VCC | 引脚 = 高阻（电平不定） | 引脚 = 上拉电压 |
| 输出 0 | 引脚 = GND | 引脚 = GND | 引脚 = GND |
| 输出高阻 | 不支持 | 支持（NMOS 关断） | 支持（NMOS 关断） |

### 4.2 波形对比

```
               推挽输出                   开漏输出（有上拉）
    VCC  ────────┐                ────┐
                 │                    │
                 │                    │  ← 上升沿较缓（电阻充电）
                 │                    │
    GND          └────────────────    └┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
              陡峭的上升沿          缓慢的上升沿（RC 充电曲线）
```

开漏输出的上升沿受上拉电阻和总线寄生电容影响，呈 RC 充电曲线。电阻越小上升越快，但功耗越大。

### 4.3 线与逻辑示例

多个开漏输出可以并联到同一条线上：

```
         VCC
          │
         [R]
          │
    ──────●────── 总线
     │    │    │
    ┌┤    ┌┤   ┌┤
    ││    ││   ││
    └┤    └┤   └┤
     │    │    │
  器件1  器件2 器件3
```

- 全部输出 1（NMOS 关断）→ 总线被上拉到高电平
- 任意一个输出 0（NMOS 导通）→ 总线被拉低
- 这种特性称为**线与**：低电平"战胜"高电平

推挽输出**不能**这样接——如果一个输出 1、另一个输出 0，两个管子会形成 VCC→GND 的直通路径，瞬间大电流烧毁芯片。

## 五、如何在 CubeMX / STM32 中配置

### 5.1 推挽输出（GPIO_PULLUP / GPIO_OUTPUT_PP）

```
GPIO_InitTypeDef GPIO_InitStruct = {0};
GPIO_InitStruct.Pin  = GPIO_PIN_0;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;    // 推挽输出
GPIO_InitStruct.Pull = GPIO_NOPULL;             // 无上下拉（推挽不需要）
GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_HIGH;
HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
```

**CubeMX 配置路径：**
Pinout 视图 → 点击引脚 → 选择 `GPIO_Output` → 在 GPIO Settings 中 `GPIO output level` → Mode 自动为推挽

### 5.2 开漏输出（GPIO_MODE_OUTPUT_OD）

```
GPIO_InitTypeDef GPIO_InitStruct = {0};
GPIO_InitStruct.Pin  = GPIO_PIN_1;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_OD;    // 开漏输出
GPIO_InitStruct.Pull = GPIO_NOPULL;             // 外部已有上拉，内部不再需要
GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_HIGH;
HAL_GPIO_Init(GPIOB, &GPIO_InitStruct);
```

**CubeMX 配置路径：**
Pinout 视图 → 点击引脚 → 选择 `GPIO_Output` → GPIO Settings → 将 `Output Mode` 改为 `Open Drain`

> **注意：** 对于 I²C 等外设，CubeMX 会自动将引脚配置为开漏输出，无需手动修改。请不要手动将已分配给 I²C 外设的引脚修改为推挽模式，否则通信会异常。

---

## 六、一句话总结

| 模式 | 一句话理解 |
|------|-----------|
| **推挽输出** | 上下各有一个管子，能主动拉高也能主动拉低，信号强、速度快。 |
| **开漏输出** | 只有下面的管子，只能主动拉低，拉高靠外部电阻，"输出 1"其实是"放手让电阻去拉高"。 |

> 选型口诀：**普通信号用推挽，总线共享用开漏，电平转换也用开漏。**

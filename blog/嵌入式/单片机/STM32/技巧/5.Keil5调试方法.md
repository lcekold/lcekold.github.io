# 一、Keil5基本调试方法

keil5调试模式需要连接调试器进行使用，如STLINK，同时需要关闭优化等级或者优化等级设置为一，避免翻译后的机器语言码跟实际情况不符，

然后介绍调试模式下的几个按钮：

* Reset:复位按钮
* Run:全速执行，暂停后可能停在任意位置
* Step:一步一步执行
* Step over:直接将函数执行完毕
* Step out:进入函数后想跳出函数可以点击
* run to cursor line:直接将代码执行到鼠标光标所指的地方
* Show Next Statement:找不到代码执行到哪里了可以点击从而回到当前代码执行的位置

# 二、设置断点

利用断点可以大大提高调试效率，使用Ctrl+B快捷键可以查询出当前设置的所有断点。

<img src="https://cdn.jsdelivr.net/gh/lcekold/blogimage@main/Network/Snipaste_2025-09-23_20-46-01.png">

Ctrl+B查询后，其中有个Count按钮，指第几次遇到这个断点位置才会停下来，对于一些循环执行的情况很有用，比如循环执行10次，我们通过设置count值为5可以让循环执行到第5次的时候停下来，然后查看其中的值。

# 第4章 EtherCAT 硬件设计

> **本章解决的问题**：软件写好了，板子该怎么做？本章说明 EtherCAT 主站和从站在硬件上的本质区别，给出 PHY 器件选型判据、配置引脚的接法，以及两个可直接照抄的从站硬件实例（微处理器型 / 直接 IO 型）。

## 主站硬件：没有特殊要求

EtherCAT 主站使用**标准以太网设备**。任何能够发送和接收符合 IEEE 802.3 以太网数据帧的控制器，都可以当 EtherCAT 主站——不需要专用 ASIC，不需要特殊 PHY。实际工程中用 PC 或嵌入式计算机做主站很常见，硬件设计上没有额外门槛。

**从站则相反**：从站必须使用专用的 ESC（EtherCAT Slave Controller）芯片，因此需要**专门设计从站硬件**。本章给出两个实例：

| 实例 | PDI 接口配置 | 特点 |
|---|---|---|
| 4.2 微处理器型从站 | 8 位异步微处理器总线 | 灵活，能跑复杂应用 |
| 4.3 直接 IO 型从站 | 直接 IO 控制 | 极简，成本与延时最优 |

## 4.1 从站 PHY 器件选择

PHY 是 ESC 和网线之间的物理层芯片，选错了从站要么不通信，要么延时大得没法用。

### 硬性约束

- **ET1100 只支持 MII 接口的 PHY**。
- 有些 ESC 器件支持 **RMII（精简 MII）**。但 RMII 的 PHY 内部用**发送 FIFO 做缓冲**，这会给从站带来额外的**转发延时和抖动**，所以**不推荐**。EtherCAT 的核心卖点就是确定性延时，任何额外缓存都是敌人。
- ET1100 的 MII 接口为降低处理/转发延时做过优化（省略了发送 FIFO），因此对 PHY 有额外要求，见第 3 章 3.2.2 物理通信端口。大多数流行 PHY 都能满足。

### 更好的 PHY 还应满足

| # | 要求 | 原因 |
|---|---|---|
| ① | 检测链接丢失的响应时间 **< 15 µs** | 满足冗余功能要求 |
| ② | 接收和发送延时**稳定** | 延时不稳 = 抖动，破坏同步 |
| ③ | 标准线缆 100 m 时，PHY 支持的**最大线缆长度 > 120 m** | 留安全极限 |
| ④ | **MI_CLK（管理接口时钟）不能固定接上拉或下拉** | 该引脚复用为配置输入引脚 |
| ⑤ | 最好有波特率和全双工自动协商 | 减少配置麻烦 |
| ⑥⑦⑧⑨ | 低功耗；3.3 V 单供电；25 MHz 时钟源；工业级温度范围 | 板级与现场环境要求 |

> **第 ④ 条是最容易踩的坑**。MI_CLK 在上电瞬间是配置输入引脚，之后才变成 PHY 管理时钟。如果按"时钟线上不能悬空"的直觉给它焊一个固定的上拉或下拉电阻，配置阶段可能被锁成错误值，上电后 MDIO 又无法正常翻转——**表现就是软件读不到 PHY 任何寄存器**。正确做法是让它由 ET1100 和 PHY 正常驱动，只在参照原厂设计时按推荐取值处理。

### 兼容性一览（型号数字已简化）

| 结论 | 厂商 / 典型型号 | 备注与原因 |
|---|---|---|
| **推荐** | Broadcom BCM5221 / BCM5222 / BCM5241 | 链接丢失响应约 1.3 µs；BCM5222 需用两只振荡器、不能用 CLK25OUT；BCM5241 物理地址仅 0/8/16/24 |
| **推荐** | Micrel KS8001L | 物理地址 1–31，地址偏移 16 |
| **推荐** | Micrel KS8721B / BT / BL / SL / CL | 链接丢失响应约 6 µs；KS8721BT 与 KS8721BL 经过硬件测试 |
| **推荐** | National DP83G40 | 响应约 250 µs，不使用 SCM 锁存时可到 1.3 µs |
| **不推荐** | AMD Am79C874/875、Broadcom BCM5208R、Intel（Level One）LXT97x 系列、Davicom DM9761、SMSC LAN83C185、ST STE100P、TDK 78Q2120C、VIA VT6303F/L | **不支持 MDI/MDI-X 自动交叉**，或缺少必要功能 |
| **不推荐** | Marvell 88E3015 / 88E3018 | **TX CLK 相位不确定**，无法保证固定相位关系 |
| **不推荐** | Micrel KS8041 | **没有信号位保持**，硬件测试未通过 |

## 4.2 微处理器操作的从站硬件设计实例

**图 4.1　Atmega128 控制的 EtherCAT 从站接口卡示意图**（原书 p.103）

<img src="https://cdn.jsdelivr.net/gh/lcekold/lcekold.github.io/img/ethercat/ethercat-book/F057_p103.png" alt="图 4.1 Atmega128 控制的 EtherCAT 从站接口卡示意图">

本书编者做的板子：用 AVR 单片机控制 ET1100 实现 EtherCAT 基本通信。组成共 5 部分：

1. **ET1100**——EtherCAT 从站控制芯片；
2. **Atmega128**（Atmel AVR 系列单片机）——4 KB 内部 RAM、128 KB 片上在线可编程 FLASH；
3. **KS8721**——以太网 PHY；
4. **H1101**（PULSE 公司）——以太网数据变压器；
5. **RJ45** 连接器。

```
[RJ45] ── [H1101 变压器] ── [KS8721 PHY] ──MII── [ET1100] ──8位并行总线── [Atmega128]
```

### 4.2.2 ET1100 配置电路

**图 4.6　ET1100 配置引脚连接图**（原书 p.106）

<img src="https://cdn.jsdelivr.net/gh/lcekold/lcekold.github.io/img/ethercat/ethercat-book/F062_p106.png" alt="图 4.6 ET1100 配置引脚连接图">

配置引脚与 PDI 引脚或其他引脚**复用**：**上电时它们作为输入，由 ET1100 锁存配置信息**；上电后这些引脚都恢复为各自的操作功能，必要时方向也可以改变。**RESET 引脚信号指示上电配置完成**。

关键配置项（本实例取值均为 0）：

| 配置名 | 引脚 | 取值 | 含义 |
|---|---|---|---|
| `C25_ENA` | L8 | 0 | 不使能 CLK25OUT2 输出 |
| `C25_SHI[0]` / `C25_SHI[1]` | L7 / M7 | 00 | 无 MII TX 相位偏移 |
| `CLK_MODE[0]` / `CLK_MODE[1]` | J11 / K2 | 00 | 不输出 CPU 时钟信号 |
| `P_CONF[0]` | J12 | 0 | 端口 0 使用 MII 接口 |
| `Transparent Mode Ena` | L3 | 0 | 不使用透明模式 |
| `P_MODE[0]` / `P_MODE[1]` | L2 / M1 | 00 | 使用 ET1100 端口 0 和端口 1 |
| `P_CONF[1]` | L1 | 0 | 端口 1 使用 MII 接口 |
| `PHYAD_OFF` | C3 | 0 | PHY 地址无偏移 |
| `LINKPOL` | K11 | 0 | `LINK_MII` 低有效 |

每个配置引脚用一只 **4.7 kΩ 电阻上拉到 3.3 V 或下拉到地**来决定取值（原板用的是 0603 封装 4.7 kΩ）。其中**有些引脚还兼 LED 状态输出功能**，所以不能随意加负载。

> **踩坑提示**：配置引脚是"上电那一刻的输入"，不是永远输入。硬接死电平会出两类问题：一是**取值错**——比如 `PHYAD_OFF` 接错，PHY 实际地址和软件假设不一致，MDIO 永远读不到 PHY；`LINKPOL` 接错则链接状态极性反了，软件以为断链其实连着，或反之。二是**功能被破坏**——上电后该引脚要当 LED 或 MI_CLK 用，固定上下拉会把输出"顶住"。所以严格按原厂配置表来，别凭感觉加电阻。

### 4.2.3 MII 接线

**图 4.7　ET1100 与 KS8721BL PHY 器件接线图**（原书 p.108）

<img src="https://cdn.jsdelivr.net/gh/lcekold/lcekold.github.io/img/ethercat/ethercat-book/F063_p108.png" alt="图 4.7 ET1100 与 KS8721BL PHY 器件接线图">

ET1100 的 MII 相关引脚分三类：

| 分类 | 信号 | 说明 |
|---|---|---|
| 端口 0 / 端口 1 数据 | `TX_ENA` | 端口 MII 发送使能 |
| | `TX_D[0..3]` | 端口 MII 发送数据 0~3 |
| | `RX_ERR` | MII 接收数据错误指示 |
| | `RX_DV` | MII 接收数据有效指示 |
| | `RX_CLK` | MII 接收时钟 |
| | `RX_D[0..3]` | 端口 MII 接收数据 0~3 |
| | `LINK_MII` | PHY 指示有效连接 |
| | `LinkAct` | LED 输出，链接状态显示 |
| 时钟 | `CLK25OUT1` | 输出时钟信号给 PHY 芯片 |
| 管理接口 | `MI_CLK` | MII 管理接口时钟（对应 MDC） |
| | `MI_DATA` | MII 管理接口数据（对应 MDIO） |

`MI_DATA` 应接外部上拉电阻，推荐 **4.7 kΩ**；`MI_CLK` 为轨到轨驱动，空闲时为高。

**KS8721BL 的特点**：

- 适用于 100BASE-TX / 100BASE-FX / 10BASE-T 物理层连接；
- 2.5 V 模拟设计，2.5 V / 3.3 V 的 I/O 电压；
- **3.3 V 单电源供电**，内部集成调压电路，功耗 < 340 mW（含输出驱动电流）；
- 完全符合 IEEE 802.3 协议标准；
- 支持 MII 和 RMII 接口；
- 支持掉电和节电模式；
- 支持 10/100 Mbps、波特率和全/半双工模式的自动协商或设置选择；
- 片上集成前端模拟滤波器；
- 具有链接、活动、全/半双工、冲突和速度等指示 LED；
- **支持 MDI/MDI-X 自动交叉**。

### 4.2.4 微处理器接口引脚接线

**图 4.8　直接 IO 控制 ET1100 接线图**（原书 p.110）

<img src="https://cdn.jsdelivr.net/gh/lcekold/lcekold.github.io/img/ethercat/ethercat-book/F064_p110.png" alt="图 4.8 直接 IO 控制 ET1100 接线图">

ET1100 与 8 位微处理器之间：**8 位数据线 D0~D7 + 14 位地址线 A0~A13**，加上一组控制线。

| 信号 | 方向 | 功能 |
|---|---|---|
| `D0~D7` | I/O | 数据总线位 0~7 |
| `A0~A13` | 输入 | 地址总线位 0~13 |
| `*CS_ESC` | 输入 | ET1100 片选 |
| `*RD_ESC` | 输入 | ET1100 读 |
| `*WR_ESC` | 输入 | ET1100 写 |
| `*BUSY_ESC` | 输出 | ET1100 操作忙 |
| `*INT_ESC` | 输出 | ET1100 中断，接到 Atmega128 的外部中断引脚 |
| `*BHE` | 输入 | ET1100 **高字节有效**输入控制 |
| `*EEPROM_Loaded` | 输出 | ET1100 初始化完成信号 |
| `SYNC0` / `SYNC1` | 输出 | ET1100 同步信号 |

**关于 `*BHE`**：数据总线只有 8 位，而 ET1100 内部寄存器是 16 位、按字对齐的。`*BHE`（Byte High Enable）就是告诉 ESC"这一次访问的是这个 16 位字的**高字节**还是低字节"。这样一条 8 位总线就能完成 16 位读写：低字节存取时 `*BHE` 无效，取高字节时 `*BHE` 有效。**这是"8 位总线访问 16 位资源"的标准做法，不是可选装饰**——漏接或接反，读回来的数据会高低字节错位。

## 4.3 直接 IO 控制的从站硬件设计实例

**图 4.9　光电隔离输出信号接线**（原书 p.111）

<img src="https://cdn.jsdelivr.net/gh/lcekold/lcekold.github.io/img/ethercat/ethercat-book/F065_p111.png" alt="图 4.9 光电隔离输出信号接线">

**图 4.10　光电隔离输入信号接线**（原书 p.111）

<img src="https://cdn.jsdelivr.net/gh/lcekold/lcekold.github.io/img/ethercat/ethercat-book/F066_p111.png" alt="图 4.10 光电隔离输入信号接线">

把 ET1100 的 **PDI 接口配置为 IO 控制**，ET1100 就能**直接控制 32 位数字量 I/O**——不需要微处理器。作者做了 16 位数字量输入 + 16 位数字量输出的 I/O 控制卡：

- **MII 部分与 4.2.3 完全相同**，照抄即可；
- **PDI 接口直接当 IO 信号用**，不再是数据总线。

### 两个必须注意的硬件点

**① 电平匹配：串 330 Ω 电阻。** ET1100 是 3.3 V 供电，外围电路是 5 V 供电。直接对接会让 3.3 V 侧承受 5 V。做法是在**每个 IO 引脚上串联 330 Ω 电阻**完成电压匹配。这是省元件的折中方案，代价是驱动能力和边沿速度有所下降，因此**不能用于高速信号，只适合数字量 IO**。

**② 光电隔离：TLP521-4。** 输入输出引脚经过光电隔离后即可直接用于外部设备控制，器件选用 **TLP521-4 光电耦合器**（四路封装）。隔离把现场侧的干扰和地电位差挡在 ESC 之外，是工业从站的标配。

### 两种从站形态的取舍

> **直接 IO 模式就像"开关直连"**：ESC 直接把信号线接到引脚上，开关一动电平就变。而**微处理器型从站像"带翻译的会议室"**——什么复杂活都能谈，但每句话都得等翻译。
>
> 前者**省成本、延时最小**，代价是只能干"开/关"这种简单活；后者灵活，能做 A/D 变换、电机脉冲输出等任何事，代价是多一颗芯片、多一层软件处理延时。**只要逻辑简单到"读输入、写输出"，就该选直接 IO。**

```
直接 IO 模式：
  EtherCAT 帧 ──> ET1100 ──(PDI 当 IO，串 330Ω)──> 光耦 TLP521-4 ──> 现场设备

微处理器模式：
  EtherCAT 帧 ──> ET1100 ──(8位并行总线)──> Atmega128 ──> 外设
                                  ↑
                         多了总线访问 + 程序处理的时间
```

## 本章小结

| 主题 | 一句话核心 |
|---|---|
| 主站硬件 | 用标准以太网设备即可，能收发 IEEE 802.3 帧就能当主站，无特殊要求 |
| 从站硬件 | 必须用专用 ESC 芯片，需要专门设计，本章给微处理器型和直接 IO 型两个实例 |
| PHY 接口类型 | ET1100 只支持 MII；RMII 的发送 FIFO 增加转发延时和抖动，**不推荐** |
| PHY 选型要点 | 链接丢失响应 < 15 µs、收发延时稳定、线缆余量 > 120 m、3.3 V 单电源、25 MHz 时钟 |
| MI_CLK 引脚 | 同时是配置输入引脚，**不能固定接上拉或下拉电阻**，否则配置错且 MDIO 不通 |
| 不兼容 PHY | 典型原因：不支持 MDI/MDI-X 自动交叉、TX CLK 相位不确定、没有信号位保持 |
| 配置引脚 | 与 PDI 引脚复用，**上电时作输入被锁存**，之后恢复功能，必要时方向可变；RESET 指示配置完成 |
| 配置接法 | 每个引脚用 4.7 kΩ 上拉到 3.3 V 或下拉到地决定取值，部分引脚兼 LED 输出 |
| 配置接错的后果 | PHYAD 错 → 读不到 PHY；LINKPOL 错 → 链接状态反了；固定顶住复用引脚 → 上电后功能失效 |
| 微处理器接口 | 8 位数据 + 14 位地址，关键控制线 `*CS_ESC`/`*RD_ESC`/`*WR_ESC`/`*BUSY_ESC`/`*INT_ESC`/`*BHE` |
| `*BHE` 的意义 | 用高字节有效信号在 8 位总线上完成 16 位访问，接错则数据高低字节错位 |
| 关键状态信号 | `*EEPROM_Loaded` 表示 ET1100 初始化完成，软件必须等它有效再访问 |
| 直接 IO 模式 | ESC 直接控制 32 位数字量 I/O，无需微处理器，成本最低、延时最小，但只能做简单开关量 |
| 电平匹配 | ET1100 为 3.3 V、外围为 5 V，IO 引脚串联 **330 Ω** 电阻匹配 |
| 光电隔离 | 用 **TLP521-4** 光耦隔离后再接外部设备，抗干扰、隔地电位差 |

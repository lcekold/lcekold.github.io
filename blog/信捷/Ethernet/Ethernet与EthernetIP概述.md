# 一、Ethernet是什么？

Ethernet（以太网）是全球最主流、最基础的有线局域网通信标准（电气与电子工程师协会定义的 IEEE 802.3 标准）。简单说，它规定了网线怎么造、接口长什么样（比如RJ45水晶头）、以及数据如何变成电信号或光信号在线上传输。

## 1.1 Ethernet是如何工作的？

以太网通信的核心，依赖于两个关键东西：

* MAC地址（物理地址）：每一个网卡出厂时都烧录了一个全球唯一的48位“身份证号”（如 AA:BB:CC:DD:EE:FF）。以太网就是靠这个地址来识别同一根网线（局域网）里的不同设备。
* 数据帧（Frame）：数据在以太网上传输时，会被打包成一块块“数据帧”。每一帧都包含：目标MAC地址、源MAC地址****、实际数据内容，以及校验码**（用于检查数据是否传错）。

当你的电脑要发数据时，它会把数据帧发到网线上，局域网里的交换机根据帧头的“目标MAC地址”，精准地把它转发给对应的设备。

## 1.2 以太网在网络七层模型的位置

* 物理层（第1层）：处理网线、电压、光纤信号。
* 数据链路层（第2层）：这就是以太网的核心层，负责把数据封装成帧，并通过MAC地址寻址。

## 1.3 Ethernet和Ethernet/IP的关系

Ethernet只涉及到物理层MAC地址以及数据链路层负责将数据封装成帧，他并不规定应用层的内容也就是具体发送的是什么数据，这个数据又应该怎么被解析，这部分内容是由Ethernet/IP 规定的

# 二、Ethernet/IP是什么？

Ethernet/IP（Ethernet Industrial Protocol）是工业以太网通讯协议，Ethernet/IP中的IP是“Industrial Protocol”（工业协议）的简称，和网际协议没有关系。

它让不同厂家的工业设备，如PLC（可编程逻辑控制器）、传感器、驱动器等，能够在一个标准以太网网络上相互理解、交换数据。

EtherNet/IP 的本质可以概括为：EtherNet/IP = 标准以太网 + TCP/IP + CIP（通用工业协议）

## 2.1 Ethernet/IP是如何工作的？

* 高效通信：生产者/消费者模型：区别于传统的一问一答，它采用“生产者/消费者”模型。一个设备（生产者）发送数据，网络上所有需要这个数据的设备（消费者）可以同时接收。这在需要将一个传感器数据同时发给PLC和HMI（人机界面）时非常高效。
* 两种核心消息类型：EtherNet/IP 将通信任务分成两类，使用不同的传输协议。

|特性|	隐式消息 (Implicit Messaging)|	显式消息 (Explicit Messaging)|
|----|----|----|
|主要用途|	传输实时的I/O数据，如“启动电机”、“当前转速”	|进行非实时配置、参数读写、诊断等|
|传输协议|	UDP (用户数据报协议)，追求速度|	TCP (传输控制协议)，追求可靠|
|通信模式|	生产者/消费者模型，高效广播	|请求/应答模型，一问一答|
|端口号|	2222|	44818|

* 对象化的世界：在EtherNet/IP的世界里，每个设备都被看作一系列“对象”的集合。比如，一个变频器可以被抽象为一个“对象”，它有“运行/停止”这样的属性，也有“启动”这样的服务。这种设计让不同设备间的互操作变得标准化。
* 数据包的封装：当你在Wireshark中抓包时，一个EtherNet/IP数据包从外到内是这样的：
  1. 以太网头部：包含源和目标MAC地址。
  2. IP头部：包含源和目标IP地址。
  3. TCP/UDP头部：包含端口号，用于区分是显式(44818)还是隐式(2222)消息。
  4. CIP封装头部：包含服务代码等控制信息。
  5. CIP数据段：这才是真正的“指令”或“数据”。

## 2.2 Ethernet/IP在网络七层模型的位置

| 层级 | 层级名称 | **EtherNet/IP 在这一层的内容** | 谁在负责？ |
| :--- | :--- | :--- | :--- |
| **第7层** | **应用层** | **CIP（通用工业协议）** <br>这是 EtherNet/IP 的**核心**！它规定了“启动电机”、“读取温度”、“下载程序”这些具体指令的**格式、语法和含义**。 | **EtherNet/IP 独有的灵魂** |
| **第6层** | **表示层** | CIP 数据编码（如字节顺序、数据类型的转换）。 | CIP 协议的一部分 |
| **第5层** | **会话层** | CIP 连接管理（建立、维持和关闭通信会话）。 | CIP 协议的一部分 |
| **第4层** | **传输层** | **TCP（端口44818）** 和 **UDP（端口2222）**。<br>TCP用于可靠的显式消息（配置、诊断），UDP用于高速的隐式消息（实时I/O数据）。 | **借用了标准 TCP/IP** |
| **第3层** | **网络层** | **IP（互联网协议）**。<br>负责通过IP地址进行跨网段的路由和寻址。 | **借用了标准 TCP/IP** |
| **第2层** | **数据链路层** | **以太网（Ethernet）**。<br>数据封装成帧，并通过MAC地址在局域网内寻址。 | **借用了标准以太网** |
| **第1层** | **物理层** | **以太网物理层**。<br>网线、水晶头、电信号/光信号的传输。 | **借用了标准以太网** |

Ethernet/IP是基于标准以太网（Ethernet）和TCP/IP的基础上，在第七层（应用层）通过CIP协议定义了工业控制“语言”的一个应用层协议。

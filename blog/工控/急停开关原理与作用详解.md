# 急停开关原理与作用详解

## 一、什么是急停开关

**急停开关（Emergency Stop Switch，简称 E-Stop）** 是一种手动操作的开关设备，在出现紧急情况时，操作人员通过按压急停按钮，**立即切断设备的危险能源**，使设备进入安全停止状态。

它通常采用**红色蘑菇头按钮 + 黄色/红色底座**的外观设计，醒目且便于紧急情况下快速操作。

---

## 二、核心作用

| 作用 | 说明 |
|------|------|
| **危险时快速停机** | 操作人员无需思考，一拍即停 |
| **切断危险能源** | 断开电机驱动、气动阀、液压泵等动力源 |
| **防止二次伤害** | 在故障持续时阻止设备意外重启 |
| **符合安全法规** | 多数国家强制要求机械设备必须配备急停 |

---

## 三、工作原理

### 3.1 机械结构原理

急停开关内部的核心是一个**自锁型常闭触点机构**：

```
正常状态（未按压）：
     ┌───┐
     │   │
─────┤   ├─────   ← 触点闭合，电路导通
     │   │
     └───┘

按压后（自锁状态）：
     ┌───┐
  ───┤   ├───    ← 触点断开，电路切断
     │ ○ │         ← 内部机构自锁，保持断开
     └───┘

复位方式：旋转（一般标记箭头方向）或拉出
```

- **常闭（NC）**：正常工作时常闭触点导通，急停回路保持通电。
- **自锁**：按下后机械锁住，不会自动弹回，必须手动复位。
- **强制断开**：即使触点熔焊，操作机构也一定能把触点推开（安全关键特性）。

### 3.2 电气原理

```
            ┌──────────────────────────────┐
            │         安全继电器模块         │
            │  ┌─────┐    ┌─────┐          │
   24V ──────┤ │急停 ├────┤ 急停 ├───────►  │──► 接触器线圈 → 电机停机
            │  │按钮1│    │按钮2│          │
            │  └─────┘    └─────┘          │
            │          ┌─────┐             │
            │     ┌────┤ 反馈 │            │
            │     │    └─────┘             │
            └─────┴────────────────────────┘
                   GND
```

急停按钮通常串联在安全回路的**常闭链**中，任何一个急停被按下，整个安全回路断开，安全继电器动作，切断主接触器。

### 3.3 双重通道（冗余设计）

ISO 13849 和 IEC 62061 要求急停电路通常采用**双通道冗余**：

- 通道 1：监测急停按钮的第 1 组 NC 触点
- 通道 2：监测急停按钮的第 2 组 NC 触点

两个通道独立检测，任何一个通道检测到断开，都触发停机。这样即使某个触点发生故障（如触点熔焊），另一个通道仍能可靠停机。

## 四、关键电气特性

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 触点类型 | 1NC / 2NC（常闭） | 部分带 1NO 用于反馈信号 |
| 额定电压 | AC 250V / DC 24V | 工业控制常用 DC 24V |
| 额定电流 | 1.5A ~ 10A | 信号回路用小电流 |
| 机械寿命 | 10 万 ~ 100 万次 | 取决于品牌和型号 |
| 防护等级 | IP65 / IP67（面板后） | 防尘防水 |
| 动作力 | 10N ~ 30N | 既防止误触，又保证紧急时易按下 |

## 五、选型与安装注意事项

### 5.1 选型要点

- **触点数量**：至少 1NC，推荐 2NC（冗余）
- **复位方式**：旋转复位（扭出）或拉出复位，必须有明确的操作标识
- **防护等级**：根据使用环境选择 IP 等级
- **认证标准**：CE、UL、TÜV、CCC 等安全认证
- **头部形状**：蘑菇头（ø30mm ~ ø60mm），越大越易拍击

### 5.2 安装要求（参考 ISO 13850 / GB/T 16754）

- **每个操作站至少一个**：操作人员在任何位置都能触及急停
- **安装在显眼位置**：红色蘑菇头 + 黄色底板，位置固定且标识清晰
- **直接断开**：急停必须直接断开危险能源，不能通过软件/逻辑间接控制
- **手动复位**：急停复位必须由人工手动操作，不能远程自动复位
- **复位后不自动重启**：复位后设备处于待机状态，需要独立启动操作才能恢复运行

### 5.3 常见错误做法

| ❌ 错误做法 | ✅ 正确做法 |
|-----------|-----------|
| 将急停串联在 PLC 输入端（仅靠软件停机） | 急停直接切断接触器线圈电源（硬件级切断） |
| 急停复位后设备自动恢复运行 | 复位后需人工确认并重新启动 |
| 用推拉式开关代替专用急停按钮 | 使用符合 ISO 13850 的标准急停开关 |
| 只在主控柜安装急停 | 每个操作工位/区域都应安装 |

## 六、电气接线方式

### 6.1 单台设备急停回路

```
24V ───┬──[急停按钮]──┬──[安全继电器线圈]── GND
       │              │
       └──[复位按钮]──┘
```

### 6.2 多台急停串联（最常见）

```
24V ───[急停1]──[急停2]──[急停3]──[安全继电器]── GND
       └──┘      └──┘      └──┘
     任何一个断开，回路即断开
```

### 6.3 带状态反馈的接线

```
                      ┌── 主回路（切断动力）
24V ──[急停1-NC]──[急停2-NC]──[安全继电器]──[接触器线圈]── GND
                                 │
                      ┌──────────┘
24V ──[急停1-NO]──[急停2-NO]──[PLC 输入]── GND
     （反馈给控制系统：急停是否被按下？）
```

## 七、常见问题 FAQ

### Q1: 为什么急停必须用常闭（NC）触点而不是常开（NO）？

- 如果使用常开触点，连接线断了时，控制系统会认为急停未被按下（误判为正常）。
- 使用常闭触点，一旦断线或接触不良，回路断开，设备停机——**故障导向安全（Fail-Safe）**。

### Q2: 为什么急停不能通过 PLC 软件实现？

- 软件可能死机、跑飞、逻辑异常。
- 急停的核心理念是**硬件级直接切断**，不依赖任何中间逻辑。
- 软件可以作为上层监控，但不能作为唯一的安全切断手段。

### Q3: 急停为什么要手动复位？

- 防止复位后设备突然启动，造成意外伤害。
- 操作人员需要确认危险已经排除，才能手动复位。

### Q4: 急停和普通停止按钮有什么区别？

| 对比项 | 急停按钮 | 普通停止按钮 |
|--------|---------|------------|
| 颜色 | 红色蘑菇头 | 通常红色/黑色平头 |
| 操作方式 | 拍击 | 按压 |
| 锁定 | 自锁（必须手动复位） | 自动复位（弹簧弹回） |
| 切断方式 | 直接切断危险能源 | 通常通过 PLC 逻辑停机 |
| 安全等级 | 需符合安全标准（PLr / SIL） | 无特殊要求 |

## 九、使用方法（操作流程）

### 9.1 正常情况下的使用

```
┌──────────────────────────────────────────────────────────────┐
│                       操作流程                                 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   ┌──────────┐    ┌──────────┐    ┌──────────┐              │
│   │ 设备正常 │────│发生异常  │────│拍下急停  │              │
│   │ 运行中   │    │/危险情况 │    │（用力按） │              │
│   └──────────┘    └──────────┘    └────┬─────┘              │
│                                         │                    │
│                                         ▼                    │
│   ┌──────────┐    ┌──────────┐    ┌──────────┐              │
│   │ 排除故障  │◄───│ 设备停止  │◄───│ 机器断电  │              │
│   │/确认安全  │    │          │    │ 立即停止  │              │
│   └────┬─────┘    └──────────┘    └──────────┘              │
│         │                                                    │
│         ▼                                                    │
│   ┌──────────┐    ┌──────────┐                              │
│   │ 旋转复位  │────│ 重新启动  │                              │
│   │（扭出）  │    │ 设备运行  │                              │
│   └──────────┘    └──────────┘                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 9.2 五个关键操作要点

**① 拍击：**
- 紧急情况下，用手掌（不是手指）用力拍击蘑菇头按钮
- 听到"咔嗒"声确认按钮已锁住
- 不需要犹豫力度，急停开关设计为可承受较大冲击力

**② 停机确认：**
- 观察设备确实已停止动作
- 确认危险源（电机、气缸、加热器等）已切断
- 若设备未停止，需要去总配电柜拉总闸

**③ 排查故障：**
- 确认急停原因（机械卡死、人员卷入、异常噪音等）
- 排除故障前不要复位急停
- 多人作业时，需要相互确认安全

**④ 复位：**
- 旋转蘑菇头（按箭头方向），听到"啪"的复位声
- 注意：复位后设备**不会自动启动**，只是解除急停状态
- 复位前确认所有人员已远离危险区域

**⑤ 重新启动：**
- 复位后，设备处于待机状态
- 需要通过正常的启动流程（按启动按钮、操作面板等）恢复运行
- 绝对禁止在复位瞬间直接送电重启

### 9.3 接线注意事项

- **双通道冗余**：有 2NC 触点的急停，两个通道都要接，不要浪费
- **不使用串联灯**：不要在急停回路上串联指示灯（会降低可靠性）
- **远离动力线**：急停信号线要与电机线、电源线保持距离，避免干扰
- **端子压紧**：急停回路属于安全回路，接线端子必须压紧、防松

## 十、一句话总结

**急停开关 ≈ 一个常闭自锁的红色大按钮，拍下去直接硬件切断动力源，让机器强制停下——不怕断线、不怕死机、不怕你犹豫。**

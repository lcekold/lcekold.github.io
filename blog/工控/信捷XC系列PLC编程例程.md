# 信捷 XC 系列 PLC 编程例程

> 适用 PLC：信捷 XC 系列（XC1/XC2/XC3/XC5）
> 编程软件：XDPPro
> 编程语言：梯形图（Ladder Diagram）/ 指令表（Instruction List）
> 两种表达方式一一对应，XDPPro 中可在"视图"菜单下随时切换显示

---

## 梯形图与指令表的关系

PLC 程序有两种等价的表达形式：

| 表达形式 | 说明 | 特点 |
|---------|------|------|
| **梯形图（LAD）** | 图形化，像电路图 | 直观，新手友好 |
| **指令表（IL）** | 文本化，像汇编语言 | 写起来快，省鼠标 |

它们**完全等价**，XDPPro 里按下快捷键就能互相切换：

```
梯形图画法（看得见）：        指令表写法（敲键盘）：
  X0      Y0              LD   X0
──┤├──(  )──              OUT  Y0

  X0    X1    Y0           LD   X0
──┤├──┤├──(  )──          AND  X1
                          OUT  Y0
```

> 在 XDPPro 中，梯形图画完后按 **F2** 可以切换到指令表视图查看对应的指令文本。

### 最常用的指令一览

| 指令 | 全称 | 梯形图等效 | 功能说明 |
|------|------|-----------|---------|
| **LD** | Load | `──┤├──` | 常开触点，逻辑开始 |
| **LDI** | Load Inverse | `──┤╱──` | 常闭触点，逻辑开始 |
| **AND** | AND | `──┤├──`（串联） | 串联一个常开触点 |
| **ANI** | AND Inverse | `──┤╱──`（串联） | 串联一个常闭触点 |
| **OR** | OR | `──┤├──`（并联） | 并联一个常开触点 |
| **ORI** | OR Inverse | `──┤╱──`（并联） | 并联一个常闭触点 |
| **OUT** | Output | `──(  )──` | 驱动线圈（Y/M/S） |
| **SET** | Set | `──(SET)──` | 置位线圈（保持 ON） |
| **RST** | Reset | `──(RST)──` | 复位线圈（保持 OFF） |
| **PLS** | Pulse | `──(PLS)──` | 上升沿脉冲输出 |
| **PLF** | Pulse Fall | `──(PLF)──` | 下降沿脉冲输出 |
| **ALT** | Alternate | `──(ALT)──` | 交替输出（翻转） |
| **TM** | Timer | `──(TM Kxxx)──` | 定时器 |
| **CNT** | Counter | `──(CNT Kxxx)──` | 计数器 |
| **CALL** | Call Subroutine | — | 调用子程序 |
| **END** | End | `──(END)──` | 程序结束 |

### 一个完整例子的两种写法

**启停自锁电路：**

```
梯形图画法：                       指令表写法：
                             0    LD   X0     ← 第 1 个触点
      ┌── X0（启动）         1    OR   Y0     ← 并联一个触点（自锁）
──┬───┤├─────────┬──┤╱──(  )──   2    ANI  X1    ← 串联常闭触点
  │   └── Y0（自锁）    X1    Y0  3    OUT  Y0    ← 线圈输出
  │                       4    END
  └── 左母线

扫描过程：
┌────────────────────────────────────────────────┐
│ ① LD X0  → 读 X0，当前结果 = X0 的状态         │
│ ② OR Y0  → 和上一步结果做"或"，结果 = X0 OR Y0  │
│ ③ ANI X1 → 和上一步结果做"与非"，结果 = 上面 AND (NOT X1) │
│ ④ OUT Y0 → 把最终结果给 Y0                     │
└────────────────────────────────────────────────┘
```

可以看到指令表就是**从上到下、从左到右**读梯形图，每个触点/线圈对应一条指令。

### 为什么还要学指令表？

| 场景 | 原因 |
|------|------|
| **键盘比鼠标快** | 熟练后敲指令比画梯形图快得多 |
| **批量修改** | 查找替换某个元件（如把 X0 全换成 X1），指令表比梯形图方便 |
| **手机/远程修改** | 有些场景只能传文本，没法传图形 |
| **理解扫描顺序** | 指令表让你更清楚 PLC 从左到右、从上到下的执行顺序 |

### XDPPro 输入指令的方法

在梯形图编辑模式下，选中一个位置后直接敲键盘：

```
选中空位置 → 按 L D 空格 X 0 回车 → 插入了一个 LD X0
选中空位置 → 按 O U T 空格 Y 0 回车 → 插入了一个 OUT Y0
选中空位置 → 按 T M 空格 K 3 0 回车 → 插入了一个 TM K30
```

XDPPro 支持直接在梯形图编辑框中输入指令文本，自动转换成图形显示。

## 例程 1：电机启动/停止控制（自锁电路）

最基本的启停控制，是 PLC 编程的"Hello World"。

### 控制要求

- 按下启动按钮 → 电机启动并保持
- 按下停止按钮 → 电机停止
- 急停断开 → 电机立即停止

### IO 分配

| 地址 | 符号名 | 说明 |
|------|--------|------|
| X0 | Start_Btn | 启动按钮（绿色，常开） |
| X1 | Stop_Btn | 停止按钮（红色，常闭） |
| X2 | EStop | 急停信号（外部急停回路常闭触点） |
| Y0 | Motor_Run | 电机运行接触器 |

### 梯形图

```
               ┌── X0 ──┐    X1         X2             Y0
               │  启动  │    停止       急停
──┬────────────┤┤───────┬──┤╱────────┤╱────────────(  )── 电机运行
  │            └── Y0 ──┘
  │               自锁
  │
  └── 电源母线                  ↑  Y0 和 X0 并联的关系
                                    按下 X0 启动 → Y0 得电
                                    → Y0 自锁触点接通 → 松开 X0 后 Y0 自保持
```

### 程序说明

- **启动**：按下 X0（瞬间导通）→ Y0 得电 → Y0 的常开自锁触点接通 → 松开 X0 后 Y0 通过自锁保持
- **停止**：按下 X1（常闭触点被断开）→ Y0 回路断开
- **关键点**：停止按钮接常闭（NC），急停也接常闭。断线时回路自动断开，**故障导向安全**

### 指令表写法

同一个程序在 XDPPro 中切换到指令表视图后看到的是：

```
      LD   X0      ← 常开触点 X0（启动按钮）
      OR   Y0      ← 并联自锁触点 Y0
      ANI  X1      ← 串联常闭触点 X1（停止按钮）
      ANI  X2      ← 串联常闭触点 X2（急停）
      OUT  Y0      ← 驱动输出线圈 Y0
      END           ← 程序结束
```

> 对比梯形图和指令表，可以看到：
> - `LD` = 接一个常开触点（开始一行逻辑）
> - `OR` = 向上并联一个触点
> - `ANI` = 串联一个常闭触点（AND + Inverse）
> - `OUT` = 输出线圈
> - `END` = 程序结束

### XDPPro 操作步骤

```
① 新建工程 → XC3-32T-E（根据自己的型号选）
② 双击"主程序（MAIN）"打开梯形图编辑区
③ 拖入常开触点（F5）→ 输入 X0
④ 拖入常开触点（F5）→ 输入 Y0
⑤ 拖入常闭触点（F6）→ 输入 X1
⑥ 拖入常闭触点（F6）→ 输入 X2
⑦ 拖入线圈（F7）→ 输入 Y0
⑧ 并联 Y0 触点到 X0 两端（选中 X0 → Ctrl+Shift+上箭头 增加向上并联分支）
⑨ 编译（F9）→ 下载到 PLC → 监控（F3）
```

## 例程 2：单按钮启停（ALT 交替指令）

用一个按钮实现"按一次启动，再按一次停止"。

### 控制要求

- 第 1 次按按钮 → 电机启动
- 第 2 次按按钮 → 电机停止
- 再按→再启动，循环交替

### IO 分配

| 地址 | 符号名 | 说明 |
|------|--------|------|
| X0 | Toggle_Btn | 单按钮（常开） |
| Y0 | Motor_Run | 电机运行 |

### 梯形图

```
        X0                     M0
──┤├──┬──────────────────────(PLS)── 上升沿脉冲
      │
      │ （PLS 指令：X0 从 OFF→ON 的瞬间，M0 导通一个扫描周期）
      │
      M0                     Y0
──┤├────────────────────────(ALT)── 交替输出
      │
      │ （ALT 指令：每触发一次，Y0 翻转一次）
      │   第 1 次 → Y0=ON
      │   第 2 次 → Y0=OFF
      │   第 3 次 → Y0=ON  ...
```

### 程序说明

- **PLS M0**：检测 X0 的**上升沿**（从 0 变 1 的那个瞬间），产生一个扫描周期的脉冲
- **ALT Y0**：每来一个脉冲，Y0 翻转一次（ON→OFF 或 OFF→ON）
- 没有自锁电路那么麻烦，两条指令就搞定

### 指令表写法

```
      LD   X0      ← 读启动按钮
      PLS  M0      ← X0 上升沿时 M0 通一个扫描周期
      LD   M0      ← 读脉冲标志
      ALT  Y0      ← 每次触发，Y0 翻转一次
      END
```

> **PLS** 和 **ALT** 是 XC 系列常用的功能指令。PLS 用于捕捉信号的"边沿"，ALT 用于实现"开关切换"。

### 等效的自锁电路写法（不用 ALT）

```
   X0      M0          M0
──┤├──┬──────────────(  )── 沿触发的中间标志
      │
      │   用沿触发实现"单按钮"效果：
   M0     Y0          Y0
──┤├──┤├────────────(  )── 如果 Y0=OFF，启动
   M0    Y0          Y0
──┤├──┤╱────────────(  )── 如果 Y0=ON，停止
      │
      │ 第 1 次按：第 1 行导通，Y0 启动
      │ 第 2 次按：第 2 行导通，Y0 停止
      │ 注意：不能写双线圈！这里用了两行分开控制
```

## 例程 3：电机正反转控制（含双重互锁）

工业现场最常见的控制需求之一。

### 控制要求

- 正转按钮 → 电机正转
- 反转按钮 → 电机反转
- 停止按钮 → 电机停止
- 正转时不能反转，反转时不能正转（互锁）
- 急停断开 → 立即停止

### IO 分配

| 地址 | 符号名 | 说明 |
|------|--------|------|
| X0 | Fwd_Btn | 正转按钮（常开） |
| X1 | Rev_Btn | 反转按钮（常开） |
| X2 | Stop_Btn | 停止按钮（常闭） |
| X3 | EStop | 急停信号（常闭） |
| Y0 | Fwd_KM | 正转接触器 |
| Y1 | Rev_KM | 反转接触器 |

### 梯形图

```
   ┌── 正转回路 ─────────────────────────────┐
          ┌── X0 ──┐    X2    X3    Y1      Y0
   ┌──────┤┤───────┬──┤├──┤├──┤╱──────(  )── 正转
   │      └── Y0 ──┘  停止  急停  反转互锁
   │         自锁
   │  ↑ Y0 和 X0 是并联关系（自锁）
   │    Y1 是串联的反转互锁（常闭）
   └──────────────────────────────────────────

   ┌── 反转回路 ─────────────────────────────┐
          ┌── X1 ──┐    X2    X3    Y0      Y1
   ┌──────┤┤───────┬──┤├──┤├──┤╱──────(  )── 反转
   │      └── Y1 ──┘  停止  急停  正转互锁
   │         自锁
   │  ↑ 结构完全对称
   └──────────────────────────────────────────
```

### 指令表写法

```
      LD   X0      ← 正转按钮
      OR   Y0      ← 自锁
      ANI  X2      ← 停止（常闭）
      ANI  X3      ← 急停（常闭）
      ANI  Y1      ← 反转互锁（串 Y1 常闭）
      OUT  Y0      ← 正转输出
                    ←（注意：LD 开始新一行）
      LD   X1      ← 反转按钮
      OR   Y1      ← 自锁
      ANI  X2      ← 停止（常闭）
      ANI  X3      ← 急停（常闭）
      ANI  Y0      ← 正转互锁（串 Y0 常闭）
      OUT  Y1      ← 反转输出
      END
```

> 可以看到：正反转的逻辑结构完全对称，两段指令除了操作的元件不同，结构一模一样。

### 重要提醒——双重互锁

**只靠软件互锁是不够的**。如果 Y0 或 Y1 的晶体管击穿短路，软件互锁就失效了。必须同时做硬件互锁：

```
               ┌── 电气原理图 ──┐
             L1                  L2
              │                   │
              │    ┌──┐           │
          ┌───┴──┤Y0├───────┬───┤N├── KM1 线圈（正转）
          │      └──┘       │   └──┘
          │               KM1_常闭
          │      ┌──┐       │   ┌──┐
          └───┬──┤Y1├───────┴───┤N ├── KM2 线圈（反转）
               │  └──┘          └──┘
               │             KM2_常闭
               └─────────────────┘

  接触器 KM1 的常闭触点串联在 KM2 线圈回路
  接触器 KM2 的常闭触点串联在 KM1 线圈回路
  一个吸合时，另一个的线圈回路被物理切断
```

> **软件互锁（梯形图）+ 硬件互锁（接触器常闭触点），缺一不可。**

## 例程 4：闪烁电路（报警指示灯）

### 控制要求

- 报警信号触发后，指示灯以 0.5 秒间隔闪烁
- 故障清除后，指示灯熄灭

### IO 分配

| 地址 | 符号名 | 说明 |
|------|--------|------|
| X0 | Alarm_In | 报警输入信号 |
| Y0 | Alarm_Light | 报警指示灯 |

### 梯形图

```
   ┌── 闪烁振荡电路 ────────────────────────┐
   T0                          T0
──┤╱────────────────────────────────────(TM)── 定时器 T0
                                         K50    定时 5.0 秒
                                                （K50 = 50 × 100ms = 5.0s）

   T0                              Y0
──┤├───────────────────────────────────(  )── 报警指示灯
                                              T0 计时未到时，Y0=ON
                                              T0 计时到后，Y0=OFF
```

### 更实用的可调闪烁电路

```
   ┌── 闪烁电路：ON 0.5s / OFF 0.5s ───────┐
   T1                          T0
──┤╱────────────────────────────────────(TM)── T0 计时
                                         K5      K5 = 500ms

   T0                          T1
──┤├────────────────────────────────────(TM)── T1 计时
                                         K5      K5 = 500ms
   T0              Y0
──┤├───────────────────────────────────(  )── 输出
```

**效果**：T0 计时 0.5s → 断开 → T1 计时 0.5s → 断开 → T0 重新开始 → 循环。Y0 在 T0 导通期间输出，呈现 0.5s 亮、0.5s 灭的闪烁效果。

## 例程 5：延时启动/延时停止

### 控制要求

- 按下启动后，电机延迟 3 秒启动
- 按下停止后，电机延迟 5 秒停止

### 梯形图

```
   ┌── 启动延迟 ────────────────────────────┐
   X0        T0                M0
──┤├──┬──────────────────────(  )── 启动触发了，等待 T0
      │
      T0
──┤├────────────────────────────────────(TM)── 3 秒延时
                                         K30     K30 = 3.0s

   ┌── 停止延迟 ────────────────────────────┐
   X1        T1                M1
──┤├──┬──────────────────────(  )── 停止触发了，等待 T1
      │
      T1
──┤├────────────────────────────────────(TM)── 5 秒延时
                                         K50     K50 = 5.0s

   ┌── 输出 ────────────────────────────────┐
   M0    M1                          Y0
──┤├──┤╱────────────────────────────────(  )── 电机输出
          │
          │ M0 = M1 已经计时完毕，此时 M1=OFF
          │ M1 计时到位后 M1=ON，Y0 断开
          │ 相当于：M0 先导通，M1 后导通
          │ Y0 = M0 AND (NOT M1)
```

### 更简洁的写法（单线圈电路）

```
   X0          X1            T1              Y0
──┤├────────────┤├──────┬──┤╱─────────(  )── 启动记忆
   │ 启动     停止     │              │
   │                    │              │
   └── Y0 ──────────────┘              │
       └── 自锁                       │
                                       │
   Y0                                  T0
──┤├────────────────────────────────(TM)── 启动延时 3s
                                    K30

   Y0                                  T1
──┤├────────────────────────────────(TM)── 停止延时 5s
   X1                                  K50
──┤├──────────────────────────────────────
       停止检测
```

## 例程 6：Modbus RTU 通信读取变频器频率

XC 系列通过串口与变频器通信，读取当前运行频率。

### 通信配置

```
变频器参数设置（以台达 VFD-M 为例）：
  P00 = 03  ← 频率来源：通信
  P01 = 03  ← 运行指令来源：通信
  P88 = 01  ← 通信地址：1 号站
  P89 = 01  ← 通信速度：9600 bps
  P92 = 04  ← 通信数据格式：8,N,2（Modbus RTU）

XDPPro 通信配置：
  COM2 → 9600, 8, N, 2 → Modbus RTU 主站
```

### 梯形图

```
   ┌── 每 100ms 读取一次变频器频率 ─────────┐
   M0（0.1s 时钟）                           ← XC 内部特殊继电器
                                     M10
──┤├──────────────────────────────────(PLS)── 每 100ms 触发一次

   M10                                       ← 脉冲触发
──┤├───────────────────────────────────[MODR K1 H2103 D0 K1]──
                                      │   │    │    │  │
                                      │   │    │    │  └── 读取 1 个字
                                      │   │    │    └───── 存放地址 D0
                                      │   │    └────────── 从站地址 2103H
                                      │   └─────────────── 从站站号 1
                                      └─────────────────── Modbus 读指令

   ┌── 处理读取到的数据 ────────────────────┐
   D0                                        ← 读取到的原始值（0~16383）
                                             对应变频器 0~60Hz
                                             换算：频率 = D0 × 60 / 16383

──┤[D0 × K60 / K16383 → D10]── 换算到 D10 中显示实际频率
```

### 常用 Modbus 指令速查

| 指令 | 功能 | 格式 |
|------|------|------|
| **MODR** | 读寄存器 | `MODR 站号 寄存器地址 D目标 长度` |
| **MODW** | 写寄存器 | `MODW 站号 寄存器地址 D源 长度` |
| **MODE** | 读线圈 | `MODE 站号 线圈地址 Y目标 长度` |
| **MODC** | 写线圈 | `MODC 站号 线圈地址 Y源 长度` |

常见变频器寄存器地址（台达系列）：

| 功能 | Modbus 地址 |
|------|------------|
| 运行频率读取 | H2103 |
| 输出电流读取 | H2104 |
| 运行指令（正转/反转/停止） | H2000 |
| 频率设定（写入） | H2001 |
| 故障状态读取 | H2100 |

## 例程 7：位移台步进电机脉冲控制

用 XC3 系列控制步进电机驱动器，实现精准定位。

### 控制要求

- 按下启动 → 步进电机转动指定圈数后停止
- 限位开关触发 → 立即停止

### IO 分配

| 地址 | 符号名 | 说明 |
|------|--------|------|
| X0 | Start_Btn | 启动按钮 |
| X1 | Home_Sensor | 原点传感器 |
| X2 | Limit_Fwd | 正向限位 |
| X3 | Limit_Rev | 负向限位 |
| Y0 | Pulse_Out | 脉冲输出（XC3 高速输出口） |
| Y1 | Dir_Out | 方向信号（ON=正转，OFF=反转） |
| Y2 | Enable_Out | 使能信号 |

### 梯形图

```
   ┌── 启动 ────────────────────────────────┐
   X0    X2    X3          M0
──┤├──┤├──┤├────────────(  )── 运行标志
   │    限位  限位
   │    (常闭) (常闭)
   │
   M0                          M0
──┤├─────────────────────────────────[PLS/DPLSF]── 脉冲输出

       ┌── PLS/DPLSF 脉冲输出指令 ──┐
       │                           │
       │  XC 系列脉冲输出指令：      │
       │  PLSF K10000 K0 Y0         │
       │   │        │   │           │
       │   │        │   └── 输出口  │
       │   │        └────── 加减速方式│
       │   └─────────────── 频率 10kHz │
       │                           │
       │  停止脉冲：STOP Y0          │
       └───────────────────────────┘

   M0           X1           M1
──┤├──────────┤├──────────(  )── 到达原点标志

   M1          T0
──┤├────────────────────────(TM)── 到位后延时等待
                            K10     1 秒

   T0                          M0
──┤├──────────────────────(RST)── 复位运行标志

   限位或急停触发时也要 STOP Y0
   X2                          Y0
──┤├──────────────────────[STOP]── 正限位停止脉冲

   X3                          Y0
──┤├──────────────────────[STOP]── 负限位停止脉冲
```

### XC 系列脉冲指令速查

| 指令 | 功能 | 说明 |
|------|------|------|
| **PLSF** | 高速脉冲输出 | `PLSF 频率 加减速 Y口` |
| **PLSR** | 带加减速脉冲 | `PLSR 频率 总脉冲数 加减速时间 Y口` |
| **STOP** | 停止脉冲输出 | `STOP Y口` |
| **SPD** | 速度检测 | `SPD X口 采样时间 D目标` |
| **HSC** | 高速计数器 | `HSC X口 D计数器` |

## 例程 8：PID 温度控制（简易版）

用 XC3 控制加热器，使温度稳定在目标值。

### 控制要求

- 设定目标温度（如 100°C）
- 读取热电偶/PT100 温度值
- PID 运算后输出控制加热器通断

### IO 分配

| 地址 | 符号名 | 说明 |
|------|--------|------|
| AD 模块 | Temp_Value | 温度传感器模拟量输入（0~10V → 0~4095） |
| Y0 | Heat_ON | 加热器控制输出 |

### 梯形图

```
   ┌── 模拟量读取 ──────────────────────────┐
   FROM K0 K0 D100 K1                        ← 读取 AD 模块通道 0 到 D100
   │    │  │   │   │
   │    │  │   │   └── 读取 1 个字           │
   │    │  │   └────── 存放到 D100           │
   │    │  └────────── 模块内寄存器地址       │
   │    └───────────── 模块编号（第 0 个扩展模块）
   │
   D100 → D102                               ← 数字滤波
   将 D100 的值经过低通滤波存入 D102
   公式：D102 = D102 × 0.8 + D100 × 0.2

   ┌── PID 运算 ────────────────────────────┐
   D102          D200        D202
  (当前值)      (目标值)    (PID 输出)
      │           │           │
      └─────┬─────┘           │
            │                 │
   PID 指令：                 │
   PID D102 D200 D202          │
       │    │    └── PID 输出值（0~4095）
       │    └─────── 目标值 SV（设定在 D200）
       └─────────── 当前值 PV（来自 AD 模块）

   ┌── 输出控制 ────────────────────────────┐
   D202          K2048                Y0
──┤[≥]────────────────────────────────(  )── 加热器
   PID输出    50% 阈值
              （4096/2）
   │
   │ D202 > 2048 → 加热器 ON
   │ D202 ≤ 2048 → 加热器 OFF
   │ 这叫"时间比例控制"，是简化的 PID 输出方式
```

### PID 参数整定口诀

```
P（比例）   ↑ 越大响应越快，太大就震荡
I（积分）   ↓ 越小积分越强，消除静差
D（微分）   ↑ 越大抑制震荡，但对噪声敏感

经验值（XC 系列，加热控制）：
  P = 200~500
  I = 50~200
  D = 0~20
```

## 例程 9：简易自动售货机逻辑

结合实际工艺的综合案例。

### 控制要求

- 投入金额（通过按钮模拟，每次 1 元）
- 选择商品 1（3 元）或商品 2（5 元）
- 金额足够时，对应商品指示灯亮
- 按下确认 → 出货电机转动 → 找零 → 恢复待机
- 金额不足时，按下退币 → 退回所有余额

### IO 分配

| 地址 | 符号名 | 说明 |
|------|--------|------|
| X0 | Coin_Btn | 投币（1 元） |
| X1 | Select_1 | 选择商品 1（3 元） |
| X2 | Select_2 | 选择商品 2（5 元） |
| X3 | Confirm | 确认购买 |
| X4 | Refund | 退币 |
| Y0 | Motor_Out1 | 商品 1 出货电机 |
| Y1 | Motor_Out2 | 商品 2 出货电机 |
| Y2 | Ready_Light | 可购买指示灯 |

### 软元件规划

| 地址 | 说明 |
|------|------|
| D0 | 当前余额（元） |
| D10 | 商品 1 价格（=3） |
| D11 | 商品 2 价格（=5） |
| M0 | 投币标志 |
| M1 | 退币标志 |
| M10 | 商品 1 可选择 |
| M11 | 商品 2 可选择 |

### 梯形图

```
   ┌── 初始化 ──────────────────────────────┐
   M8002                                     ← XC 上电瞬间 ON 的特殊继电器
──┤├──────────────────────────────────[MOV K0 D0]── 余额清零
                                       [MOV K3 D10]── 商品 1 价格
                                       [MOV K5 D11]── 商品 2 价格

   ┌── 投币处理 ────────────────────────────┐
   X0                              M0
──┤├──────────────────────────────────(PLS)── 投币脉冲

   M0
──┤├───────────────────────────────[INC D0]── 余额 +1（INC 指令）

   ┌── 商品选择（金额判断） ──────────────────┐
   D0           D10                  M10
──┤[≥]──────────────────────────────────(  )── 商品 1 可选
   余额         3 元

   D0           D11                  M11
──┤[≥]──────────────────────────────────(  )── 商品 2 可选
   余额         5 元

   M10                                 Y0

   M11                                 Y1

   X3    M10                              ← 按确认 & 余额够商品 1

              │  (余额 - 价格)
              │
   X3    M11
──┤├──┤├──────┴─[SUB D0 D11 D0]───[SET Y1]── 扣款、出货

   ┌── 出货电机定时停止 ────────────────────┐
   Y0                              T0
──┤├──────────────────────────────────(TM)── 商品 1 出货 3 秒
                                    K30
   T0
──┤├───────────────────────────[RST Y0]── 停止出货

   Y1                              T1
──┤├──────────────────────────────────(TM)── 商品 2 出货 3 秒
                                    K30
   T1
──┤├───────────────────────────[RST Y1]── 停止出货

   ┌── 退币 ────────────────────────────────┐
   X4                              M1
──┤├──────────────────────────────────(PLS)── 退币脉冲

   M1
──┤├───────────────────────────────[MOV K0 D0]── 余额清零
   └──────────────────────────────────────────
```

## 常见陷阱与提示

> **双线圈**：同一个 Y 或 M 不能在两处写线圈输出，逻辑会以最后执行的为准。如果必须多处控制，改用 SET/RST 或中间 M 过渡。

> **八进制地址**：X0~X7 之后是 X10（不是 X8），X17 之后是 X20。输入 Y 地址时要注意，写错地址编译不会报错，但硬件对不上。

> **断电保持**：XC 的 D 寄存器默认断电清零。如果需要断电保持数据，使用**锁存型 D 寄存器**（范围见手册，不同型号不同），或在 PLC 参数中设置断电保持区域。

> **CALL 嵌套**：子程序最多嵌套 8 层。如果 CALL 套 CALL 超过 8 层，程序跑飞，监控时会发现程序卡住。

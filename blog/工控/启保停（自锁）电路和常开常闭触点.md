# 启保停（自锁）电路和常开常闭触点

## 一、概述

**启保停电路**（Start-Protect-Stop Circuit）是工业控制中最基础也是最核心的电路结构之一。它实现了对电机等负载的**启动保持**和**停止控制**功能，是几乎所有电气控制系统的基石。

"启保停"三个字分别代表：
- **启** — 启动按钮（常开按钮，瞬间闭合）
- **保** — 自锁触点（利用自身辅助触点维持导通状态）
- **停** — 停止按钮（常闭按钮，瞬间断开）

---

## 二、常开触点和常闭触点

### 2.1 基本概念

| 类型 | 符号 | 常态（未动作时） | 动作时 | 文字符号 |
|------|------|------------------|--------|----------|
| 常开触点（NO） | 两条平行线且断开 | 断开（不导通） | 闭合（导通） | NO（Normally Open） |
| 常闭触点（NC） | 两条平行线且连接 | 闭合（导通） | 断开（不导通） | NC（Normally Closed） |

### 2.2 常开触点（NO）

- **常态下**：触点处于断开状态，电路不导通
- **动作后**：触点闭合，电路导通
- **典型应用**：启动按钮、限位开关的到位触发、压力开关的超压报警等
- **在启保停电路中**：用作**启动按钮**（SB1），轻触一下即闭合，松手后自动复位断开

### 2.3 常闭触点（NC）

- **常态下**：触点处于闭合状态，电路导通的
- **动作后**：触点断开，电路切断
- **典型应用**：停止按钮、急停开关、热继电器过载保护触点、门禁开关等
- **在启保停电路中**：用作**停止按钮**（SB2），轻触一下即断开，松手后自动复位闭合

### 2.4 记忆要点

> **常开** = 通常状态下是**开**路（不导通）
> **常闭** = 通常状态下是**闭**合的（导通）

按下按钮时：
- 常开按钮：按下去**接通**
- 常闭按钮：按下去**断开**

## 三、启保停（自锁）电路原理

### 3.1 电路结构

启保停电路的核心由以下部分组成：

```
                 ┌──────────────────────────────────┐
                 │           L（火线/电源正极）        │
                 │                    ↓               │
                 │         ┌──── [停止 SB2] ────┐     │
                 │         │  （常闭按钮）       │     │
                 │         │                    ↓     │
                 │         │    ┌── [启动 SB1] ─┐    │
                 │         │    │  （常开按钮）  │    │
                 │         │    │       ↓        │    │
                 │         │    │  ┌────[KM]───┐ │    │
                 │         │    │  │  自锁触点  │ │    │
                 │         │    │  └───────────┘ │    │
                 │         │    └──────┬─────────┘    │
                 │         │           ↓              │
                 │         │      [KM 线圈]           │
                 │         │      （接触器线圈）       │
                 │         │           ↓              │
                 │         └────────── N（零线/电源负极）│
                 └──────────────────────────────────┘
```

### 3.2 文字描述电路连接

**主回路**（以电机控制为例）：
```
L1,L2,L3 → 断路器 QF → 接触器主触点 KM → 热继电器 FR → 电机 M
```

**控制回路**：
```
火线 L → 热继电器常闭触点 FR → 停止按钮 SB2（常闭）
        → 启动按钮 SB1（常开）‖ 接触器辅助常开触点 KM（自锁并联）
        → 接触器线圈 KM → 零线 N
```

### 3.3 工作过程

#### 启动过程

1. 按下 **SB1**（常开启动按钮）→ 闭合导通
2. 电流路径：L → FR → SB2 → SB1（按下闭合）→ KM线圈 → N
3. **KM 线圈得电** → 接触器吸合
4. 接触器吸合后同时发生两件事：
   - **主触点闭合** → 电机得电启动运行
   - **辅助常开触点 KM 闭合**（自锁触点）
5. 松开 SB1 → SB1 复位断开
6. 但此时 **KM 自锁触点已经闭合**，电流通过自锁触点继续为线圈供电
7. **电路自锁保持** → 电机持续运行

#### 停止过程

1. 按下 **SB2**（常闭停止按钮）→ 断开
2. 控制回路被切断 → **KM 线圈失电**
3. 接触器释放 → 所有 KM 触点复位
   - **主触点断开** → 电机停止
   - **自锁触点断开** → 为下一次启动做准备
4. 松开 SB2 → SB2 复位闭合
5. 但此时自锁触点已断开，电路不会自行启动

#### 过载保护

- 当电机过载时，**热继电器 FR** 动作
- FR 常闭触点断开 → 控制回路切断 → 接触器释放 → 电机停止
- 实现了**过载保护**功能

## 四、自锁（Self-holding）的本质

自锁是启保停电路的核心机制，其本质是：

> **利用接触器自身的辅助触点来维持线圈的得电状态**

### 4.1 为什么需要自锁？

启动按钮 SB1 是**瞬动型**按钮——按下接通，松手断开。如果没有自锁触点，松手后线圈立即失电，电机也就停止了。这显然不符合"按一下启动，持续运行"的需求。

### 4.2 自锁的实现条件

自锁得以实现需要满足：

1. **启动信号**（SB1按下）使线圈得电
2. 线圈得电后，其自身的辅助常开触点闭合
3. 该辅助触点在电气上**并联**在启动按钮两端
4. 启动按钮松开后，自锁触点**替代**启动按钮维持供电

### 4.3 自锁与互锁的关系

| 概念 | 作用 | 典型应用 |
|------|------|----------|
| **自锁** | 维持自身回路的导通 | 启保停电路、单台电机控制 |
| **互锁** | 防止两个回路同时导通 | 正反转控制、星三角切换 |

> 自锁和互锁经常配合使用。例如在电机正反转控制中，正转回路需要**自锁**维持运行，同时正转和反转回路之间需要**互锁**防止短路。

## 五、常见扩展电路

### 5.1 多地控制

将多个启动按钮**并联**、多个停止按钮**串联**即可实现多地控制：

```
L → FR → [停止A]—[停止B]—[停止C]——┬—[启动A]—┬—→ KM线圈 → N
                                    │          │
                                    ├—[启动B]—┤
                                    │          │
                                    ├—[启动C]—┤
                                    │          │
                                    └——[KM自锁]—┘
```

- 任意一个启动按钮按下都可启动
- 任意一个停止按钮按下都可停止

### 5.2 带指示灯电路

```
L → FR → SB2 —┬— SB1 —┬— KM线圈 → N
              │        │
              │        └— KM自锁 —┘
              │
              ├— KM常开 —— 运行指示灯（绿色）→ N
              │
              └— KM常闭 —— 停止指示灯（红色）→ N
```

- 停止时：红色指示灯亮（通过 KM 常闭触点）
- 运行时：绿色指示灯亮（通过 KM 常开触点），红灯灭

### 5.3 延时启保停（配合时间继电器）

```
L → FR → SB2 —┬— SB1 —┬— KT线圈 → N
              │        │
              │        └— KM自锁 —┘
              │
              └—— KT延时闭合触点 —— KM线圈 → N
```

按下 SB1 → KT 线圈得电自锁 → 延时到达 → KT延时触点闭合 → KM 得电 → 负载启动

## 六、PLC 中的启保停实现

在 PLC 编程中，启保停逻辑通常使用**梯形图（Ladder Diagram）** 实现。

### 6.1 梯形图实现

```
  ┌────┤│───────────────────────────────────────────( )──┐
  │    停止       启动      运行                      运行 │
  │   X0          X1        Y0                          Y0 │
  │   ─┤├─────────┤├─────────┤├───────────────────────( ) │
  │    │           │          │                           │
  │    │           └──┤├──────┘                           │
  │    │               自锁                                │
  └────┴──────────────────────────────────────────────────┘
```

| PLC 元件 | 对应物理元件 |
|----------|-------------|
| X0（常闭） | 停止按钮 SB2 |
| X1（常开） | 启动按钮 SB1 |
| Y0（线圈） | 接触器 KM |
| Y0（自锁触点） | KM 辅助常开触点 |

### 6.2 语句表（STL）实现

```
LD    X0        // 读取停止按钮（常闭）
AND   X1        // 与启动按钮（常开）
OR    Y0        // 或自锁触点
OUT   Y0        // 输出到接触器线圈
```

### 6.3 梯形图另一种更安全的写法

实际工程中更推荐将停止信号放在前面并取反，避免 PLC 输入损坏时无法停止：

```
  ┌───┤├────────────────────────────────────────────( )───┐
  │   启动       停止取反     运行                     运行 │
  │   X1         X0           Y0                         Y0 │
  │ ──┤├────┬────┤├────┬──────┤├──────────────────────( ) │
  │        │         │         │                          │
  │        └──┤├─────┘         │                          │
  │            运行            │                          │
  └────────────────────────────┴──────────────────────────┘
```

对应指令：
```
LD   X1        // 启动信号
OR   Y0        // 自锁
AND  X0        // 停止信号（常开+取反逻辑=安全停止）
OUT  Y0
```

> **注意**：在 PLC 中编写启保停时，停止信号通常采用**常开触点+程序中取反**的方式，这样即使 PLC 输入点损坏或线路断裂，系统也能保证安全停止（Fail-Safe）。

## 七、常见故障与排查

| 故障现象 | 可能原因 | 排查方法 |
|----------|----------|----------|
| 按下启动无反应 | 停止按钮损坏开路 | 万用表测 SB2 两端是否导通 |
| 按下启动无反应 | 热继电器过载保护动作 | 检查 FR 是否复位 |
| 启动后松手即停 | 自锁触点未闭合或接触不良 | 检查辅助触点是否正常闭合 |
| 启动后松手即停 | 自锁回路接线错误 | 检查自锁触点是否与 SB1 并联 |
| 无法停止 | SB2 损坏失效 | 更换停止按钮 |
| 无法停止 | 接触器卡死（机械故障） | 更换接触器 |
| 频繁启停 | 自锁触点接触不良抖动 | 清洁或更换辅助触点 |

## 八、安全注意事项

1. **急停按钮必须使用常闭触点** — 确保断线时也能切断电路
2. **热继电器常闭触点串联在控制回路中** — 实现过载自动保护
3. **控制回路需配置短路保护**（熔断器或小型断路器）
4. **维修时必须切断电源**，严禁带电操作
5. **接触器的选择**必须与负载额定电流匹配，留有余量
6. **PLC 程序中**停止信号建议用常开输入+软件取反，确保断线安全

## 九、总结

启保停（自锁）电路是工业控制的**基石电路**，其核心是利用接触器（或继电器）自身的辅助触点实现自锁保持。理解启保停电路是掌握更复杂控制逻辑（正反转、星三角、顺序控制等）的前提。

| 知识点 | 要点 |
|--------|------|
| 常开触点 | 常态断开，动作闭合 → 用于启动信号 |
| 常闭触点 | 常态闭合，动作断开 → 用于停止/保护信号 |
| 自锁 | 用自身触点维持导通状态 |
| 启保停 | 启动 → 自锁保持 → 停止信号切断 |
| 多地控制 | 启动并联，停止串联 |
| 安全原则 | 常闭停止，断线保护，过载保护 |

# 大致规则：

（1）制作一个车模完成推箱子游戏（待定）。

（2）车模顶部固定一个标识牌便于全局摄像头识别车模位置和方向。 该信息传递到游戏引擎软件。

（3）控制电路板上安装有摄像头，拍摄车模上固定的小液晶屏（手机屏幕）上的游戏画面， 识别到车模为止和游戏虚拟环境下的目标。 控制车模运动完成特定游戏任务。

（4）竞赛任务详见《人工智能视觉组》文档描述。

传感器： 摄像头

MCU平台：NXP

车模：四轮三轮麦克纳姆轮福来轮

人数：四人

# 大致思路：

1. 制作车模：三轮（全向轮）车模

2. 固定标识牌：便于全局摄像头识别车模位置和方向

3. 控制电路板：安装摄像头，拍摄车模上固定的小液晶屏（手机屏幕）上的游戏画面

4. 识别车模位置和方向：将信息传递到游戏引擎软件

5. 控制车模运动：完成特定游戏任务

# 具体技术选择

1. 使用无线通信模块：实现车模与游戏引擎软件之间的数据传输

2. 使用PYQT：实现游戏引擎软件的图形界面
